# Anyloc — команда на связи

Рекламный лендинг Anyloc. Обновлённая композиция опирается на референс https://www.atlassian.com/#product: крупная типографика, светлые продуктовые секции, тёмная сцена связей и интерактивные примеры продукта. Логотип и демонстрации интерфейса сохранены из исходного проекта.

## Запуск

Установка зависимостей не нужна. Из корня проекта:

```sh
node scripts/prepare-pages.mjs
python -m http.server 8765 --directory _site --bind 127.0.0.1
```

Открыть http://127.0.0.1:8765. После изменений повторите сборку и обновите страницу: имена ресурсов с хешами предотвращают загрузку старого кэша. Используйте HTTP, поскольку скрипты работают как ES-модули.

## Устройство

- `dist/index.html` — структура и русскоязычное содержание.
- `dist/connected.css` — новый дизайн, иллюстрация первого экрана, сцена связей и адаптивная раскладка.
- `dist/main.js` — собственные SVG-аватары, четыре значка событий, 13 связей между восемью людьми и общий анимационный цикл.
- `dist/lower.js`, `dist/product-ui.js` — интерактивные примеры телефона и панели, сценарии, вкладки, отчёты и диалоги.
- Остальные CSS и локальные изображения — сохранённая база интерфейсов. Старые Three.js и Lenis остаются в assets, но новый первый экран их не загружает.

Сигнал проходит по кривой за 1,65 секунды. После прибытия аватар мягко подсвечивается и увеличивается, справа снизу появляется значок. События: вход на объект, написание отчёта, фотография и завершение смены. Анимация приостанавливается вне экрана и в скрытой вкладке; видимая кнопка паузы убрана. При `prefers-reduced-motion` сцена статична. Все персонажи и данные иллюстративные, подключения к рабочей базе нет.

## Проверка и сборка

```sh
node --check dist/main.js
node --check dist/lower.js
node --check dist/product-ui.js
node scripts/prepare-pages.mjs
```

Сборка создаёт `_site`, добавляет хеши содержимого в имена CSS/JS и обновляет ссылки. Все пути относительные, включая ресурсы в подпапке GitHub Pages. Существующий workflow публикует `main` в GitHub Pages; рабочая ветка редизайна — `design/connected-people`.

Типографика использует Inter с кириллицей: умеренная насыщенность заголовков и более свободные интервалы, вдохновлённые маркетинговой типографикой Atlassian. Charlie Sans — собственный брендовый шрифт Atlassian; здесь используется открытая альтернатива, а не точная копия. Шрифты с кириллицей и лицензии OFL сохранены в `dist/assets/fonts`; внешние запросы к Google Fonts не нужны. Секция сценариев полностью переработана: присутствие, обслуживание и клининг имеют отдельные иллюстрации и ссылки на нужную демонстрацию. SVG-портреты ограничены круговыми масками, значки действий выполнены в едином стиле. Старые DESIGN-NOTES и ASSET-NOTES описывают предыдущую версию; этот README описывает текущую.

Раздел возможностей (`#features`) — единая интерактивная композиция: журнал с просмотром подробностей, выбор роли, назначение NFC-метки и пояснения к форматам выгрузки. Права и данные показаны как иллюстративные примеры.
