# Anyloc — команда на связи

Рекламный лендинг Anyloc. Обновлённая композиция опирается на референс https://www.atlassian.com/#product: крупная типографика, светлые продуктовые секции, тёмная сцена связей и интерактивные примеры продукта. Логотип и демонстрации интерфейса сохранены из исходного проекта.

## Запуск

Установка зависимостей не нужна. Из корня проекта:

```sh
python -m http.server 8765 --directory dist --bind 127.0.0.1
```

Открыть http://127.0.0.1:8765. Используйте HTTP, поскольку скрипты работают как ES-модули.

## Устройство

- `dist/index.html` — структура и русскоязычное содержание.
- `dist/connected.css` — новый дизайн, иллюстрация первого экрана, сцена связей и адаптивная раскладка.
- `dist/main.js` — собственные SVG-аватары, четыре значка событий, 13 связей между восемью людьми и общий анимационный цикл.
- `dist/lower.js`, `dist/product-ui.js` — интерактивные примеры телефона и панели, сценарии, вкладки, отчёты и диалоги.
- Остальные CSS и локальные изображения — сохранённая база интерфейсов. Старые Three.js и Lenis остаются в assets, но новый первый экран их не загружает.

Сигнал проходит по кривой за 1,65 секунды. После прибытия аватар мягко подсвечивается и увеличивается, справа снизу появляется значок. События: вход на объект, написание отчёта, фотография и завершение смены. Анимация приостанавливается вне экрана и в скрытой вкладке; есть ручная пауза. При `prefers-reduced-motion` сцена статична. Все персонажи и данные иллюстративные, подключения к рабочей базе нет.

## Проверка и сборка

```sh
node --check dist/main.js
node --check dist/lower.js
node --check dist/product-ui.js
node scripts/prepare-pages.mjs
```

Сборка создаёт `_site`, добавляет хеши содержимого в имена CSS/JS и обновляет ссылки. Все пути относительные, включая ресурсы в подпапке GitHub Pages. Существующий workflow публикует `main` в GitHub Pages; рабочая ветка редизайна — `design/connected-people`.

Шрифт Manrope загружается из Google Fonts, резервный — Arial. При изменении окружения проверьте доступность внешнего шрифта. Старые DESIGN-NOTES и ASSET-NOTES описывают предыдущую версию; этот README описывает текущую.
